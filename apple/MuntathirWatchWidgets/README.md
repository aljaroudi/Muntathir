# Watch complications

WidgetKit extension for [MuntathirWatch](../MuntathirWatch/): Hijri day/month, next prayer time, and countdown. All support inline, circular, rectangular (including Smart Stack), and corner families, with SwiftUI previews.

Next-prayer and countdown displays exclude hidden prayers and non-prayer times. Enable `group.com.aljaroudi.Muntathir` for both watch targets. App Groups share data locally; WatchConnectivity transfers settings between devices.

Build with the `MuntathirWatch` scheme. Paired-device synchronization and watch-face rendering require device validation. See [Apple setup](../).
