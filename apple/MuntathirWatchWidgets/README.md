# Watch complications

These WidgetKit complications for [MuntathirWatch](../MuntathirWatch/) show the Hijri date, the next prayer, and a countdown. Each comes in the inline, circular, rectangular (including Smart Stack), and corner families. Hidden prayers and non-prayer times are skipped.

Build with the `MuntathirWatch` scheme, and enable `group.com.aljaroudi.Muntathir` on both Watch targets.
