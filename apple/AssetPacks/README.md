# Quran translations

The app and daily-ayah widget bundle English, Spanish, German, Russian, and simplified/traditional Chinese translations. Selection supports Auto, None, and explicit languages. No downloads are required.

Other database sources and Apple-hosted packs are retained for future use. The shipping targets exclude those databases. Existing Apple-hosted assets need no changes.

Validate the shipping bundle with `python3 apple/AssetPacks/assets.py check-bundle <app-or-ipa>`.
